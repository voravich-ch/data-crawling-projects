# Grammy Data Collection
This repository contains python scripts to scrape `artist-level` data from artists nominated or awarded by Grammy.

As of April, 2022, we have collected `5,244` artists data stored in `grammyAwards.artists` collection. We used the artist names collected from Grammy to scrape the sidebar containing important information about the artist and the wikipedia page (See: [grammyGoogleSearch.py](https://github.com/simoneSantoni/music-market/blob/master/grammyAwards/grammyCrawl/grammyGoogleSearch/grammyGoogleSearch.py); [Sample Image](sample_image.png)).
